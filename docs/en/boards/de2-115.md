# DE2-115

## 1. Reference

The Terasic DE2-115 has a Cyclone IV E (`EP4CE115F29C7`) with 128 MB of SDRAM, 8 MB of NOR FLASH, 2 MB of SRAM and an RS-232 UART. The package is in `boards/de2-115/` and the research sheet in `Plans/Multi-FPGA/placas/de2-115.md` of the Capstone repository. The package format is in [formato.md](formato.md) and the table of boards in [placas.md](placas.md).

## 2. Platforms

Two platforms run on this board, both with the console on the JTAG UART and the eight-digit display.

| Platform | Folder | FLASH | RAM | Use |
| :--- | :--- | :--- | :--- | :--- |
| `de2-115-n2` | `src/cyclone-iv-e/de2-115-n2/` | emulated in M9K blocks, 252 KiB | emulated in M9K blocks, 128 KiB | level N2, no memory chip of the board |
| `de2-115` | `src/cyclone-iv-e/de2-115/` | NOR chip, 1 MiB of the chip | SDRAM of two 16-bit chips, 64 MiB of the map | level N4 |

The Quartus project of each one comes from `riscv-tools board generate`, and the `config.yaml` of the platform only says where it is and how the host reaches the memories.

## 3. NOR FLASH

The chip has an 8-bit bus, and a 32-bit word costs four reads. The `nor_flash_ctrl` controller runs on the core clock and counts the cycles of the chip timings with a pin margin of 5 ns. The SoC speaks in absolute addresses and the chip in offsets: the generated top subtracts the start of the FLASH region (`0x1000`) from the read and command addresses, so that offset 0 of the chip is `0x1000`. The chip sector is 64 KiB, which is why bank B starts at `0x81000` (offset `0x80000`). The FLASH region of the map covers 1024 KiB, the window of the region router.

The erase, program and protect commands arrive through the FLASH controller of the Peripherals (window `FLASH_CTRL`), which is the path of the program update.

## 4. SDRAM

The two 16-bit chips share control, address and `DRAM_CLK` and form a 32-bit bus with the mask `DRAM_DQM[3:0]`. The controller uses `dq_width` equal to 32, burst of 1 and 25 word address bits.

| Item | Value |
| :--- | :--- |
| Controller clock (`mem`) | 100 MHz |
| Address map | 64 MiB RAM at `0x40000000` |
| Debug port | reaches the $2^{25}$ words: bit 24 of the address travels in bit 3 of the operation code |

The map covers 64 MiB of the 128 MB because the cache tag keeps the address bits up to 25, which covers a 64 MiB window. Widening the cache tag is the condition to map the whole board.

## 5. Particulars

| Item | Treatment |
| :--- | :--- |
| IDCODE | `020F70DD`, the same as the 10CL120 and the EP3C120; `board scan` tells the board by its package |
| Reset | `KEY[0]`, active low, which is also a bit of the `keys` role |
| `SLEW_RATE` | the `cyclone-iv-e` family does not get the option, which Quartus refuses on 3.3-V LVTTL (error 169303) |
| Display | eight digits, `quartus.display_digits: 8` in `config.yaml` |
| Fetch clock | the platform does not declare `clocks.fetch`: the fetch clock is the core one, without the offset the DE0-CV uses |
