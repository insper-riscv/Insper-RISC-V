# KPI scripts

Both scripts run from the root of the repository.

## 1. How to use

```bash
# 1. Generate the KPIs of the current version
python3 scripts/kpi_report.py --output docs/current_2026_1.json

# 2. Compare with the baseline of the previous group
python3 scripts/compare_kpis.py \
  --baseline docs/baseline_2025_2.json \
  --current  docs/current_2026_1.json
```

## 2. What each KPI measures

| KPI | Measure |
| :--- | :--- |
| 1 | CPU clock frequency |
| 2 | cocotb test coverage, as the percentage of passing tests |
| 3 | Supported RV32I and RV32M instructions |

## 3. Files

| File | Role |
| :--- | :--- |
| `docs/baseline_2025_2.json` | Snapshot of the previous group, which is not edited |
| `docs/current_2026_1.json` | Generated by `kpi_report.py` |
| `scripts/kpi_pipeline.json` | Description of the KPI pipeline |
