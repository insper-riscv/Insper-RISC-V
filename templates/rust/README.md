# RV32 Rust application

Edit `src/main.rs`, then run **RV32: Prepare Project** and **RV32: Simulate**.
Use **Dev Containers: Reopen in Container** for the registered SDK/toolchain.
This is a bare-metal `no_std` application; host test harnesses are disabled.
The SDK selects the Rust target from `cpu_profile` in `rv32.toml`.
